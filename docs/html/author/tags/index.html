Boolean arguments

Function

Explanation

Explanation

true if M is a diagonalizable matrix

Rank(m)

gives rank of the matrix M

DiagonalOf(M)

the diagonal entries of M as a row vector

NullRank(M)

gives the rank of the null space of M
