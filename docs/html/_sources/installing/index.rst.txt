.. note::

   Customize command examples using the "Session Variables" panel in the left sidebar.
   Set Remote user (|remote-user|) and Remote host (|remote-host|) to match your environment.
   The defaults are "remote-user" and "remote-host" and are stored only in your browser.
   PDF/LaTeX outputs use the defaults.
